Grandio Interiors website (built on the NEST Bootstrap template)

Open index.html in a browser (internet needed for Google Fonts only).
index.html          - page content and project tiles
js/projects.js      - the 8 project detail pages (edit text, info and gallery per project here)
css/style.css       - colours and styles (copper #a8743a, forest #24403b)
js/main.js          - scrolling and project filter
img/                - replace template photos with real Grandio project photos, keeping the same file names
mail/contact_me.php - contact form handler (sends to prince@grandiointeriors.com; needs PHP hosting)
